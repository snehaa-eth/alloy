Alloy wireframes · v2

Drawn from UX_MAP v2 with final tokens (TOKENS v0.3): dark default, colour from content, gold ≤ 3%, burgundy ≤ 10%, one Anton hero per screen, 3 type sizes, word budgets. The test network is marked by the thin blue top edge and TEST on balances. v1 is kept in wireframes.html. Motion is in motion-prototype.html. Imagery rules, image list and AI prompts are in IMAGERY.md. All images here are original CSS/SVG art, with no external images and no brand photos. The coloured logo monograms are placeholders for Coinbase API icon_url logos.

Decided defaults (founder can override): email via Resend · phone-only users see change notices in Activity only · Founding # from the indexer (first Issued event order) · /try uses Privy email code + auto faucet · Demo lab = 3 demo baskets on 10-min notice.
